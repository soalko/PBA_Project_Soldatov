# Система управления концертными программами

Консольное приложение для ведения реестра концертных программ,
исполнителей и площадок, а также продажи и отмены билетов.

## Назначение
Приложение решает задачу упорядочивания работы концертного агента
или организатора мероприятий: ведёт реестр программ и исполнителей,
учитывает площадки и расписание, позволяет продавать и отменять
билеты с расчётом цены по промокоду. Данные сохраняются в JSON-файлах.

## Возможности
- ведение списка исполнителей: добавление, поиск, фильтрация по жанру;
- ведение списка площадок: добавление, поиск, проверка вместимости,
  отбор по минимальной вместимости, сортировка;
- создание концертных программ с привязкой исполнителя и площадки;
- проверка доступности площадки на выбранную дату;
- продажа и отмена билетов с расчётом цены по промокоду;
- сохранение и загрузка всех данных в JSON-файлах.

## Структура проекта
- main.py — точка запуска и главное меню;
- programs.py — функции работы с концертными программами;
- artists.py — функции работы с исполнителями;
- venues.py — функции работы с площадками;
- tickets.py — продажа билетов и проверка доступности площадки;
- storage.py — сохранение и загрузка данных в JSON;
- utils.py — вспомогательные функции ввода с обработкой ошибок;
- data/ — JSON-файлы с данными проекта;
- tests/ — автоматизированные тесты pytest.

## Основные функции

| Функция                                                                 | Что делает                                                                                                                                           |
|-------------------------------------------------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------|
| check_program_creation()                                                | проверка корректности данных при создании концертной программы.                                                                                      |
| check_venue_availability()                                              | проверка доступности площадки на выбранную дату и подсчёт свободных мест (с преобразованием строкового значения количества проданных билетов в int). |
| calculate_ticket_price()                                                | расчёт итоговой стоимости билета с учётом промокода.                                                                                                 |
